# Copacabana — assets

Assets gráficos asociados al contexto **Copacabana** (campaña / evento / activación Corona). Usar cuando la presentación trate específicamente de Copacabana o cuando el brief lo mencione.

## Archivos disponibles

### `corona-logo-white.png`
**Logo primario Corona (corona + wordmark "Corona") en blanco, PNG con fondo transparente.**
- Es el logo institucional en versión blanca — **usar solo sobre fondos oscuros** (Corona Blue `#0C2340` ideal). Sobre blanco o amarillo el logo desaparece.
- Formato PNG, resolución pequeña (~440×270). No escalarlo a tamaños muy grandes (pixelado). Si se necesita grande, pedirle al usuario la versión vectorial / SVG.
- Fondo transparente — se puede colocar directamente sobre cualquier color oscuro de la paleta.
- **No modificar**: no recolorear, no recortar la corona del wordmark, no aplicar sombras / gradientes, no distorsionar proporción.
