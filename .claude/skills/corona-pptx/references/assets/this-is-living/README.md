# This Is Living — assets

**"This Is Living"** es el **tagline oficial** de la marca Corona (manual VBI pág. 57–61). Representa el posicionamiento central de la marca: el momento Corona como celebración del estar vivo. Está tipografiado en **Corona Display** (el bespoke typeface condensado y en all-caps, reservado para headlines above-the-line), y se usa con o sin textura grabada según el contexto.

## Cuándo usar el tagline

El tagline **no se agrega a cada slide**. Reservalo para:

- **Portada** de la presentación (como bajada del título o como statement de cierre de la portada).
- **Slide de cierre** (último slide, en lugar de "Gracias").
- **Separadores de sección** dentro de presentaciones extensas, cuando se quiere reforzar el tono brand.
- Slides de **statement conceptual** donde el tagline es el mensaje (y queda "elevado" al estatus de titular).

**No usarlo en:**

- Slides de contenido regular (datos, listas, procesos) — satura y debilita el tagline.
- Slides de performance / tracking numérico — el tono comercial no encaja.
- Más de 1–2 slides por presentación (si se repite demasiado pierde fuerza).

## Archivos

Las tres variantes son **blanco sobre fondo transparente** → usar **solo sobre fondos oscuros** (Corona Blue `#0C2340` ideal). Para fondos claros no hay versión en esta carpeta; pedir al usuario la variante en Corona Blue si se necesita.

### `corona-this-is-living-lockup-white.png`
**Lockup completo**: logo Corona (crown + wordmark) arriba + tagline "THIS IS LIVING" debajo. Es el formato más "firmado" — comunica Corona + tagline como una unidad. Ideal para **portada** o **cierre** cuando el logo de marca y el tagline aparecen juntos.

### `this-is-living-tagline-textured-white.png`
**Solo el tagline**, tipografía Corona Display en all-caps, **con textura grabada (art brush)**. Es la aplicación oficial descrita en el manual VBI pág. 59 ("WITH TEXTURE ADDED"). Es la versión expresiva — reforza el tono craft / artesanal. Usar como statement conceptual, separador de sección, o cita destacada.

### `this-is-living-tagline-clean-white.png`
**Solo el tagline**, tipografía Corona Display en all-caps, **sin textura** ("TYPESET"). Versión limpia, más corporativa. Usar cuando el contexto requiere un tono formal (presentación institucional, reporting) o cuando la textura competiría visualmente con otro elemento de la slide (ej. un gráfico, una foto con mucho grano).

## Cómo elegir

| Contexto | Variante |
|---|---|
| Portada / cierre donde conviven logo y tagline | `corona-this-is-living-lockup-white.png` |
| Statement, separador, cita (tono craft) | `this-is-living-tagline-textured-white.png` |
| Statement, separador, cita (tono formal) | `this-is-living-tagline-clean-white.png` |

Si ya hay un logo Corona por separado en la slide, usar **solo el tagline** (una de las dos variantes de arriba). Si el tagline va solo como cover sin logo visible, usar el lockup.

## Reglas de uso

- **No modificar**: no recolorear, no reproducir con otra tipografía, no reescribir el tagline en otra variante (Esto es Vivir, Así se Vive, etc. — el tagline oficial es "THIS IS LIVING" en inglés y en all-caps).
- **No agregar textura manualmente** a la versión clean, ni quitar la textura de la versión texturizada. Son dos versiones oficiales distintas, no una pre-procesada de la otra.
- **No combinar el tagline con el sub-brand** (ej. no escribir "CORONA CERO — THIS IS LIVING" o "CORONA SUNSETS — THIS IS LIVING"). El tagline aplica a Corona marca madre; las sub-marcas tienen sus propios registros.
- Área de reserva alrededor del tagline equivalente a la altura de una letra ("L" de "LIVING" sirve de referencia).
- **Tamaño**: Corona Display está pensado para usarse grande (manual VBI pág. 61). No achicar el tagline a tamaño de body copy (menos de 20pt aprox.) — pierde presencia y la textura queda ilegible.
